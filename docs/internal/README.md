# Internal notes

Working notes, session prompts, audits, and submission artifacts belong **here** (`docs/internal/`), not at the repository root.

This keeps the root README recruiter-facing while preserving project history for contributors.

Examples of files that live in this folder:

- `CLAUDE.md`, `MASTER_PROMPT.md`, `PROJECT_CONTEXT.md`
- `FINAL_AUDIT_REPORT.md`, `SUBMISSION_PACKAGE.md`
- `MuGate_Project_Report.docx`

Do not put credentials or production secrets in these docs.
